Gloriedi Café ☕

Página web para una cafetería enfocada en la presentación de sus productos y la interacción con los clientes.

Sobre el proyecto
Este sitio busca mostrar la variedad de cafés disponibles, compartir la opinión de nuestros clientes y permitir que los usuarios nos envíen sus consultas de forma directa mediante un formulario de contacto.

Desarrollado como proyecto de práctica para maquetación y diseño web básico.

Tecnologías
- HTML5
- CSS3
